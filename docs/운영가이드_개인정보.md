# 개인정보 보호 운영 가이드

PAPS-IMS는 서버 없이 교사 본인의 Google Sheets를 DB로 사용합니다. 학생 개인정보(이름·학번·성별·신체정보·체력측정값)가 시트에 저장되므로, 아래 수칙을 지켜 주세요.

## 1. 시트 공유 설정 (가장 중요)

- **링크 공유를 켜지 마세요.** 시트 공유 설정은 "제한됨(초대된 사용자만)"을 유지합니다.
  - 확인: Google Sheets → 우측 상단 공유 → "일반 액세스"가 **제한됨**인지 확인
- 공동 측정 교사가 있다면 **개별 계정 초대**(편집자)로만 공유하고, 학년말에 권한을 회수합니다.
- 시트 사본을 개인 기기·타 계정으로 내려받아 보관하지 않습니다.

## 2. 계정·토큰

- 앱 로그인 토큰은 **브라우저 sessionStorage에만** 저장되며 탭을 닫으면 사라집니다. 공용 PC에서는 사용 후 반드시 탭을 닫으세요.
- 앱은 다음 Google 권한(스코프)만 요청합니다:
  - `spreadsheets` — 측정 데이터 읽기/쓰기 (교사 본인 시트에 한함)
  - `drive.file` — 앱이 만든 파일 접근 (전체 드라이브 접근 아님)
  - `openid profile email` — 로그인 사용자 표시용
- 앱은 어떤 서버로도 데이터를 전송하지 않습니다. 모든 데이터는 브라우저 ↔ Google Sheets 직접 통신입니다.

## 3. 데이터 최소화·보존

- 학생 등록 시 필수 항목은 학번·이름·성별·학년·반뿐입니다. 키/몸무게는 선택 입력입니다.
- 전출·졸업 학생은 **비활성화(소프트 삭제)** 를 기본으로 사용하고, 법정 보존 필요가 없는 데이터는 학년말에 학급 완전 삭제로 정리합니다.
  - ⚠️ 학급 완전 삭제는 되돌릴 수 없습니다.
- PDF/Excel 내보내기 파일에는 학생 실명이 포함됩니다 — 배포 전 수신 대상을 확인하고, 개인 카드는 해당 학생·학부모에게만 전달합니다.

## 4. 사고 대응

- 시트가 잘못 공유된 경우: 공유 설정에서 즉시 권한 회수 → 파일 → 버전 기록으로 열람 시점 확인
- 계정 탈취 의심 시: Google 계정 보안 점검(myaccount.google.com/security) → 앱 권한에서 PAPS-IMS 접근 철회 후 재로그인

## 부록: OAuth 안내 문구 (가정통신문용)

> 본교는 학생건강체력평가(PAPS) 기록 관리를 위해 교사 계정의 Google 스프레드시트를 사용합니다. 데이터는 담당 교사의 Google 계정에만 저장되며 외부 서버로 전송되지 않습니다. 저장 항목: 학번, 이름, 성별, 학년·반, (선택) 키·몸무게, 체력측정 기록.
